# Pinewoods

Booking app for Pinewoods Cabin: Summit, Sunset, Sunrise 1 and Sunrise 2.

- **Home**: the month's income, occupancy, commission, balances still due, and next check-ins.
- **Calendar**: a week board of all four cabins, or a month calendar for one cabin. The same cabin can't be booked twice on one night.
- **Bookings**: bookings by month and cabin, plus a guest search.
- **Money**: Income, Expenses and Outcome, month by month for each cabin.

This repo holds only the app code. Bookings live in a private Supabase database that only invited team members can sign in to.
No client data is stored here.

Open the site on a phone and choose **Add to Home Screen** to install it.
